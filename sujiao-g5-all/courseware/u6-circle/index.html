圆的认识与计算

圆的特征、周长与面积的探究

📐 数学五年级苏教版
01 圆的认识 知识 ▼
圆是平面内到定点距离等于定长的所有点组成的图形。

🔵 圆的各部分名称：
• 圆心O：圆的中心点
• 半径r：圆心到圆上任意一点的线段
• 直径d：通过圆心且两端在圆上的线段
• d = 2r，即直径是半径的2倍

🎨 圆的画法：
① 定圆心 → ② 定半径 → ③ 旋转圆规画出圆周

📌 圆的特征：
• 同一圆内所有半径都相等
• 同一圆内所有直径都相等
• 圆是轴对称图形，有无数条对称轴
• 圆心决定圆的位置，半径决定圆的大小
02 圆的周长 知识 ▼
圆的周长 = π × 直径 = 2πr
C = πd = 2πr

π（圆周率）：圆的周长除以直径的商，约等于3.14。
π是一个无限不循环小数！

🌰 例题：
① 半径3cm的圆，周长是多少？
C = 2×3.14×3 = 18.84(cm)

② 周长25.12m的圆，半径是多少？
r = C÷(2π) = 25.12÷6.28 = 4(m)

③ 半圆的周长 = 圆周长的一半 + 直径
半圆弧长 + 直径 = πr + 2r

📌 记忆技巧：
圆周长 = 「两派啊」(2πr)，派大约是3.14
03 圆的面积（上） 知识 ▼
圆的面积怎么求？用转化的策略！

🔬 推导过程：
把圆平均分成若干等份（越分越多），拼成一个近似的长方形。
长方形的长 ≈ 圆周长的一半 = πr
长方形的宽 = 圆的半径 = r

所以：圆的面积 = πr × r = πr²
公式：S = πr²

🌰 基础练习：
① r=4cm，求面积：S = 3.14×4×4 = 50.24(cm²)
② d=10m，求面积：r=5m，S = 3.14×5×5 = 78.5(m²)
③ 周长31.4cm，求面积：r=31.4÷3.14÷2=5，S=3.14×25=78.5(cm²)
04 圆的面积（下）——环与组合 知识 ▼
🔵 圆环的面积：
S(环) = S(大圆) - S(小圆) = πR² - πr² = π(R²-r²)

🌰 环形跑道外圈半径10m，内圈半径8m，环形面积？
S = 3.14×(10²-8²) = 3.14×36 = 113.04(m²)

🔵 扇形：圆的一部分
扇形面积 = 圆面积 × (圆心角÷360°)
S(扇) = πr² × n/360

🔵 组合图形：
正方形中剪最大圆 → 利用率78.5%（π/4）
圆中剪最大正方形 → 边长 = √2×r

📌 外方内圆：S(阴影) = 正方形面积 - 圆面积
📌 外圆内方：S(阴影) = 圆面积 - 正方形面积
05 圆的综合应用 知识 ▼
圆的知识在生活中无处不在！

🚲 自行车轮子：周长2m，每分钟转100圈→每分钟走200m
🏟️ 操场跑道：直道+半圆，计算一圈长度
🌳 树干的直径：量树干周长，除以π得到直径
🍕 披萨面积：12寸(直径)披萨面积 = 3.14×6×6 = 113.04(in²)

🧮 思维拓展——等周问题：
在周长相等的平面图形中，圆的面积最大！
周长相同：圆面积 > 正方形面积 > 长方形面积

🔍 证明：周长=12.56
圆面积 = 12.56×12.56/(4×3.14) ≈ 12.56
正方形面积 = (12.56/4)² = 9.86
圆更大！这就是水滴是球形的原理~
