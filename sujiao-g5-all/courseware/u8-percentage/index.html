百分数

百分数的意义、读写与生活中的应用

📐 数学五年级苏教版
01 百分数的意义 知识 ▼
什么是百分数？

表示一个数是另一个数的百分之几的数，叫做百分数。
百分数也叫百分率或百分比，用符号 % 表示。

🌰 例子：
• 及格率98% → 100人中有98人及格
• 含棉量100% → 全部是棉
• 浓度75% → 100份中有75份的溶质

📌 关键：百分数不写成分数形式，而是用%表示。
比如 37/100 写成 37%，读作「百分之三十七」。

百分数表示两个数的比率关系，不表示具体数量！
所以不能说「一根绳子长50%米」❌
02 百分数与分数、小数的互化 知识 ▼
三种形式之间的转化是小考必考！

🔹 小数→百分数：小数点向右移两位，添%
0.35 = 35% 1.2 = 120% 0.075 = 7.5%

🔹 百分数→小数：去掉%，小数点向左移两位
45% = 0.45 8% = 0.08 230% = 2.3

🔹 分数→百分数：先化成小数（分子÷分母），再化成百分数
3/4 = 0.75 = 75% 1/8 = 0.125 = 12.5%

🔹 百分数→分数：写成 分母是100 的分数再化简
25% = 25/100 = 1/4 60% = 60/100 = 3/5

🎯 小口诀：小数百分互化，移动小数点就对了！
03 求百分率 知识 ▼
百分率（百分比）= 比较量 ÷ 标准量 × 100%

常见百分率：
• 及格率 = 及格人数÷总人数×100%
• 出勤率 = 出勤人数÷总人数×100%
• 成活率 = 成活棵数÷总棵数×100%
• 命中率 = 命中次数÷总次数×100%
• 出油率 = 油的质量÷原料质量×100%

🌰 例题：六(1)班50人，数学测验48人及格，及格率是多少？
48÷50×100% = 0.96×100% = 96%

⚠️ 注意：百分率不能超过100%吗？
一般情况不超过100%，但增长率、完成率可以超过100%！
04 求一个数的百分之几 知识 ▼
求一个数的百分之几是多少？用乘法！

公式：标准量 × 百分率 = 比较量

🌰 例题：
① 一本书200页，看了40%，看了多少页？
200 × 40% = 200 × 0.4 = 80（页）

② 商品打八五折，原价600元，现价多少？
600 × 85% = 600 × 0.85 = 510（元）

③ 一桶油倒出30%后还剩14千克，原来多少千克？
14 ÷ (1-30%) = 14 ÷ 0.7 = 20（千克）

🔑 已知部分和百分率求整体 → 用除法！
比较量 ÷ 百分率 = 标准量
05 生活中的百分数 生活 ▼
百分数在我们身边无处不在！

🛒 折扣：八折=80% 九五折=95% 对折=50%
原价×折扣=现价

💰 税率：营业税=营业额×税率
个人所得税收起征点为5000元/月

💵 利率：利息=本金×利率×时间
银行存款年利率约1.5%-3%

📊 增长率：增长率=(现在-原来)÷原来×100%
本月销量比上月增长15%

🌱 浓度：浓度=溶质质量÷溶液质量×100%
一杯糖水含糖20克，水180克，浓度=20/(20+180)=10%
