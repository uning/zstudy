简易方程

用字母表示数、等式的性质与解方程

📐 数学五年级苏教版 🤖AI + 🔊TTS
01 用字母表示数 知识 ▼
我们已经学过用字母表示运算律和公式。在方程中，我们用字母表示未知数。

🔤 字母可以表示：
· 数量关系：一支笔x元，3支笔=3x元
· 计算公式：长方形面积S=ab
· 运算律：a+b=b+a

📝 注意：数字和字母相乘时，数字在前，乘号可省略。
3×a = 3a a×b = ab 1×x = x

含字母的式子也可以代入数值计算！
当a=5时，3a+2 = 3×5+2 = 17
02 等式的性质 知识 ▼
等式就像天平，两边保持平衡！

⚖️ 等式的性质1：
等式两边同时加上（或减去）同一个数，等式仍然成立。
例：x+3=10 → x+3-3=10-3 → x=7

⚖️ 等式的性质2：
等式两边同时乘（或除以）同一个不为0的数，等式仍然成立。
例：5x=20 → 5x÷5=20÷5 → x=4

🎯 解方程就是利用等式性质，求出未知数的值！
03 解方程（一） 知识 ▼
解形如 x+a=b 和 x-a=b 的方程：

类型①：x+a=b
解：x = b - a
例：x+3.5=8.2 → x=8.2-3.5=4.7

类型②：x-a=b
解：x = b + a
例：x-2.7=5.3 → x=5.3+2.7=8

类型③：a-x=b
解：x = a - b
例：12-x=5 → x=12-5=7

🔑 口诀：加变减，减变加，移项要变号！

验算：把解代入原方程，看两边是否相等。
04 解方程（二） 知识 ▼
解形如 ax=b 和 x÷a=b 的方程：

类型④：ax=b
解：x = b ÷ a
例：6x=30 → x=30÷6=5

类型⑤：x÷a=b
解：x = b × a
例：x÷4=2.5 → x=2.5×4=10

类型⑥：a÷x=b（进阶）
解：x = a ÷ b
例：15÷x=3 → x=15÷3=5

🔑 口诀：乘变除，除变乘！

📍 难点提醒：两边同时操作，不要漏了任何一项！
05 列方程解决实际问题 知识 ▼
五步法列方程解应用题：

1️⃣ 找未知数：设什么为x
2️⃣ 找等量关系：题目中隐藏的相等关系
3️⃣ 列方程：根据等量关系写方程
4️⃣ 解方程：用等式的性质求解
5️⃣ 检验作答：代入检验并写答句

🌰 例题：商店卖出12个篮球，还剩8个，原来有多少个？
设原来有x个：x-12=8 → x=20

🌰 买3支钢笔和5支铅笔共付21元，钢笔每支5元，铅笔每支？
设铅笔每支x元：3×5+5x=21 → 15+5x=21 → x=1.2
