用转化的策略巧解数学问题

📐 数学五年级苏教版
01 转化的策略是什么？ 策略 ▼
转化是一种重要的数学思想方法。遇到复杂的、陌生的数学问题时，想办法把它变成简单的、熟悉的问题来解决。

就像曹冲称象——把称大象的重量转化成称石头的重量！

常见的转化方法：
① 化不规则为规则（如不规则图形→规则图形）
② 化未知为已知（如新问题→已学过的方法）
③ 化繁为简（如复杂计算→简单计算）
④ 化数为形（如数量关系→线段图）
02 面积问题中的转化 公式 ▼
不规则图形的面积怎么求？用转化！

🔹 补形法：在图形上补一块，变成规则图形
例：L形面积 = 大长方形面积 - 小长方形面积

🔹 割补法：把图形切割后重新拼成规则图形
例：平行四边形→割补→长方形

🔹 旋转法：旋转图形的一部分，组成规则图形
例：梯形两腰中点连线，旋转后拼成平行四边形

📌 关键：找到转化的路径，用已知公式计算！
03 巧算中的转化 知识 ▼
计算题也可以用转化策略！

🔹 凑整法：99+256 = 100+256-1 = 355
把接近整十整百的数先凑整再修正

🔹 拆数法：25×44 = 25×4×11 = 100×11 = 1100
把其中一个数拆成方便计算的因数

🔹 等差数列求和：1+2+3+...+100 = (1+100)×100÷2 = 5050
首尾配对，化成乘法

🔹 分数巧算：1/2+1/4+1/8+1/16 = 1-1/16 = 15/16
画图转化，一目了然！
04 应用题的转化策略 实践 ▼
应用题三步转化法：

① 画图转化：把文字变成线段图或示意图
② 关系转化：找出数量之间的等量关系
③ 列式转化：把关系写成算式

🌰 例题：买了3支钢笔和2本笔记本共花28元，钢笔比笔记本贵4元。钢笔和笔记本各多少元？

转化思路：把2本笔记本换成2支钢笔，要多花2×4=8元
28+8=36 → 5支钢笔 → 钢笔36÷5=7.2元
笔记本=7.2-4=3.2元

✅ 检验：3×7.2+2×3.2=21.6+6.4=28 ✓
05 生活应用与思维拓展 生活 ▼
转化策略无处不在！

🏀 体育：投球命中率 → 转化成中了几球和总共几球
💰 购物：满100减20 → 转化成打折计算
🏠 装修：铺地砖需要多少块 → 转化成面积÷单块面积
⏰ 行程：相遇问题 → 转化成速度和×时间

思维拓展题：
正方形边长为10cm，四个角各剪去边长为2cm的小正方形，求剩余面积。

转化：大正方形面积 10×10=100cm²
四个小正方形 4×2×2=16cm²
剩余：100-16=84cm²
