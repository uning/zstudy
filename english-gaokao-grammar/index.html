基础 ①

基础 ②

被动语态矩阵：be + done

视图：

核心规律：16 个时态中只有 10 个有被动语态。4 个完成进行时 + 将来进行时 + 过去将来进行时 没有被动——因为句中两个 be 会连在一起（*been being*），无法自然发音，英语中会用其他方式替代。

高考考法 ①：空格后有名词 → 用形容词性物主代词（my book）；空格后无名词 → 用名词性物主代词（The book is mine）。
高考考法 ②：动词 / 介词后用宾格（between you and me）；注意 its（它的）与 it's（it is）的辨析是经典陷阱。
基础 ④

介词：小词大坑

介词不能单独作句子成分，后面必须接名词、代词或相当于名词的成分作宾语。

表时间

in 年/月/季on 具体某天at 时刻点 by 截止until 直到within 之内after about 大约之后

表地点方位

in 在…内on 在…上at 在某点 under 在…下into 到…里inside / outsidefrom behind 从后面

表方式关系

with 和…一起by 通过for 为了 of 属于to 朝向about 大约/关于without 没有throughout 遍及
高考常考：① in / on / at 时间辨析（in 2025, on Monday, at 7:00）；② 固定搭配（depend on, succeed in, be interested in）；③ "介词 + which / whom" 引导定语从句（the way in which…）。

常考 ②

非谓语动词：三步判断法

找逻辑主语：非谓语动词的动作是谁发出的？通常是句子的主语或被修饰的名词。
判主被动：逻辑主语发出动作 → 主动（doing / to do）；承受动作 → 被动（done）。
判时间：表目的 / 将来 → to do；表主动 / 进行 → doing；表被动 / 完成 → done。
to do

目的、将来、未发生
To pass the exam, he studies hard.
固定：want / decide / hope + to do

doing

主动、进行
The girl singing on stage is my sister.
固定：avoid / enjoy / finish + doing

done

被动、完成
The book written by Lu Xun is famous.
固定：have / get sth done

常考 ③

三大从句：连接词决策表

从句类型识别方法高频连接词
名词性从句从句作主语 / 宾语 / 表语不缺成分用 that；缺"什么"用 what；表"是否"用 whether / if
定语从句从句修饰前面的名词（先行词）指人 who / whom / that；指物 which / that；表时间地点原因 when / where / why
状语从句从句表时间、条件、让步等逻辑时间 when / while / until；条件 if / unless；让步 although / even if；结果 so…that
只用 that 不用 which 的经典场景：先行词被最高级 / 序数词 / the only / the very 修饰，或先行词是不定代词（all, everything, nothing）。
例：This is the best film that I have ever seen.

特殊句式

倒装：Not until / Only + 状语 / Never 开头 → 助动词提前（Not until midnight did he come back.）
强调：It is / was + 被强调部分 + that…
省略：状语从句主语与主句一致且含 be → 可省（When (he was) asked, he smiled.）

主谓一致 & 独立主格

就远原则：with / together with / as well as 连接时，谓语看前面主语。
就近原则：there be / either…or / not only…but also 看最近主语。
独立主格：名词 / 代词 + 分词，自带逻辑主语（Weather permitting, we will go.）

虚拟信号词：suggest / demand / insist / require 后的宾语从句用 (should) do；wish / if only / would rather 后按上表退一步时态。
