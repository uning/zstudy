词法 ①

构词法：词性转换是语法填空半壁江山

派生（加词缀）

否定前缀：un- happy, dis- agree, im- possible
名词后缀：-tion, -ment, -ness, -er/or, -ist
形容词后缀：-ful, -less, -able, -ous, -ive
副词后缀：-ly　动词后缀：-ize, -en, -ify

合成（两词合一）

class + room → classroom
worth + while → worthwhile
home + work → homework
out + standing → outstanding

转化（词性直接变）

water n. 水 → v. 浇水
book n. 书 → v. 预订
empty adj. 空的 → v. 倒空
google n. → v. 搜索

高考考法：语法填空给出一个词，要求按句子成分变形——缺谓语变动词（care → cared），缺定语变形容词（care → careful），修饰动词变副词（careful → carefully），作主宾语变名词（careful → carefulness）。口诀：先定句子成分，再选词性，最后变形。
词法 ②

名词：可数与复数是基本功

可数名词复数规则

  • 一般加 -s：book → books
  • s / x / ch / sh 结尾加 -es：box → boxes
  • 辅音 + y → ies：city → cities
  • f / fe → ves：knife → knives（特例 roof → roofs）
  • 不规则：child → children, foot → feet, mouse → mice, sheep → sheep

高频不可数名词（不加 s）

informationadvicenews progressfurniturehomework knowledgeequipment
所有格：有生命用 's（Tom's book），无生命用 of（the name of the book），双重所有格 a friend of mine。
高考考法：① many / few / one of + 复数；much / little + 不可数；② 主谓一致看名词真身：The number of students is（数量是单数），A number of students are（学生们是复数）。
词法 ③

冠词：a / an / the / 零冠词

冠词核心用法例句
a / an泛指"一个"；an 看发音不看字母an hour / honest boy；a university / European
the特指、独一无二、序数/最高级、乐器、姓氏复数、the + 形容词表一类人the sun；the first；play the piano；the Smiths；the rich
零冠词球类/三餐/学科/语言、by + 交通、复数泛指play basketball；have lunch；by bus；Dogs are loyal.
高考考法：① 固定搭配记牢：have a cold, in the 1990s, on the whole, as a result；② 有无 the 意思不同：in hospital（住院）vs in the hospital（在医院里）；③ 语法填空空格后是可数名词单数且无冠词 → 优先考虑填 a/an/the。

不定代词高频组：both（两者都）/ either（任一）/ neither（都不）；another（三者以上另一个）/ the other（两者中另一个）/ others（泛指其余）/ the others（特定范围其余全部）。
it 的三大身份：① 指天气/时间/距离（It is raining.）② 形式主语/宾语（It is important to learn. / I find it hard.）③ 强调句骨架（It is...that）。
经典陷阱：空格后有名词 → 形容词性物主（my book）；无名词 → 名词性物主（mine）；its（它的）≠ it's（it is）；between you and me 用宾格。
词法 ⑤

介词：小词大坑

介词不能单独作句子成分，后面必须接名词、代词或相当于名词的成分作宾语。

表时间

in 年/月/季on 具体某天at 时刻点 by 截止until 直到within 之内since 自从for + 时段

表地点方位

in 在…内on 在…上at 在某点 under 在…下into 到…里inside / outsidethroughout 遍及from behind 从后面

表方式关系

with 和/用by 通过for 为了 of 属于to 朝向about 关于without 没有from among 从…中
高考常考：① in/on/at 时间辨析（in 2025, on Monday morning, at 7:00）；② 固定搭配：depend on, succeed in, be strict with, be famous for；③ 介词 + which/whom 引导定从：the way in which, the person to whom；④ 无提示词语法填空的常客就是介词。
词法 ⑥

时态：16 矩阵 × 标志词

4 种时间 × 4 种状态 = 16 个时态。★ 为高考高频。点击任意格子查看构成与例句。

必考辨析：① 有 since / so far / in recent years → 现在完成时；有 yesterday / ago / in 2019 等明确过去时间 → 一般过去时；② by + 过去时间 → 过去完成时；③ when / while 表"那时正在" → 过去进行时。
词法 ⑦

被动语态：be + done

视图：

核心规律：16 个时态中只有 10 个有被动：4 个完成进行时 + 将来进行时 + 过去将来进行时无被动（两个 be 连在一起 been being 无法自然发音）。
高频特殊考点：① 主动形式表被动：The book sells well. / The door won't lock.；② need / want / require + doing = + to be done（需要被…）；③ 系动词无被动：taste / feel / sound；④ 短语动词被动不丢介词：The children are looked after well.
词法 ⑧

非谓语动词：三步判断法

找逻辑主语：非谓语的动作是谁发出的？通常是句子主语或被修饰的名词。
判主被动：逻辑主语发出动作 → 主动（doing / to do）；承受动作 → 被动（done）。
判时间：目的/将来 → to do；主动/进行 → doing；被动/完成 → done；先于谓语完成且主动 → having done。
to do

目的、将来、未发生
To pass the exam, he studies hard.
固定接 to do：want / decide / hope / refuse / afford

doing

主动、进行
The girl singing on stage is my sister.
固定接 doing：avoid / enjoy / finish / mind / suggest

done

被动、完成
The book written by Lu Xun is famous.
固定：have / get sth done（让某事被做）

一词两义辨析：stop to do（停下来去做）vs stop doing（停止做）；remember / forget 同理；try to do（努力做）vs try doing（试着做）。
句法 ⑨

三大从句：先定类型，再选连接词

从句类型识别方法高频连接词
名词性从句从句作主语 / 宾语 / 表语 / 同位语不缺成分用 that；缺"什么/谁"用 what / who；表"是否"用 whether（有 or not 只用 whether）
定语从句从句修饰前面的名词（先行词）指人 who / whom / that；指物 which / that；表时间/地点/原因 when / where / why；表所属 whose
状语从句从句表时间、条件、让步等逻辑时间 when / while / until / as soon as；条件 if / unless / as long as；让步 although / even if；结果 so…that；目的 so that
定从铁律：先行词被最高级/序数词/the only/the very 修饰，或先行词是 all / everything / nothing 等不定代词 → 只用 that。介词后只用 which / whom（in which, to whom）。
解题顺序：① 划出从句范围 → ② 判断从句类型 → ③ 看从句内部是否缺成分 → ④ 按上表选词。例：This is the best film that I have ever seen.（最高级 + 缺宾语 → that）
句法 ⑩

虚拟语气：三行表 + 信号词

虚拟时间if 从句主句
与现在相反did / werewould / could / might + do
与过去相反had donewould / could / might + have done
与将来相反did / were to do / should dowould / could / might + do

信号词与句型

  • wish / if only / would rather + 退一步时态
  • as if / as though + 退一步时态
  • It's (high) time + did（早该…了）
  • without / but for + 名词（含蓄虚拟）：Without your help, I would have failed.

(should) do 家族

suggest / demand / insist / require / order / advise 后的宾语从句，谓语用 (should) + 动词原形：He suggested that we (should) start early.（注意：suggest 表"表明"、insist 表"坚持认为"时不虚拟）

难点：① 错综时间：从句与过去相反、主句与现在相反（If you had studied hard, you would be a student here now.）② if 省略倒装：Were I you / Had I known / Should it rain。
句法 ⑪

主谓一致：三大原则

语法一致

主语单数谓语单数。each / every / either / neither + 单数：Each student has a book. 不定代词 someone / anything + 单数。

意义一致

集合名词看意思：The family is big（整体）/ The family are watching TV（成员们）。分数/百分数 + of 名词：谓语跟名词走（Two thirds of the water is…）。

就近 / 就远

就近：there be / either…or / neither…nor / not only…but also 看最近主语。就远：with / together with / as well as / rather than 看前面主语。

高频考点：① A number of + 复数动词（许多）vs The number of + 单数动词（…的数量）；② 主语后跟 with / as well as 短语是干扰项，谓语永远看真正的主语：The teacher, with his students, is here.；③ 动名词/不定式作主语用单数：Reading is fun.
句法 ⑫

倒装句：全部倒装 × 部分倒装

全部倒装（谓语整体提前）

  • here / there / now / then 开头：Here comes the bus.
  • 方位介词短语开头：Under the tree sat an old man.
  • 表语提前：Gone are the days…
  • ⚠️ 主语是代词时不倒装：Here it is.

部分倒装（只提助动词）

  • 否定词开头 Never / Hardly / Seldom / Not until：Not until midnight did he come back.
  • Only + 状语开头：Only then did I realize my mistake.
  • So / Such 开头：So fast did he run that…
  • neither / nor / so 表"也不/也是"：Neither do I.
  • 虚拟 if 省略：Had I known… / Were I you…
高考考法：看到否定词 / Only / So 开头，立刻检查后面是否倒装——主语和谓语的顺序就是答案。注意 Only 修饰主语时不倒装：Only Tom knows it.
句法 ⑬

强调句：It is / was … that …

It is / was + 被强调部分 + that / who + 其余部分

被强调部分是人 → 可用 who；其余一律 that。be 只有 is / was 两种，时态看句子。

变形与疑问

  • 一般疑问：Was it in 1998 that he was born?
  • 特殊疑问：Where was it that you met her?
  • not until 强调：It was not until midnight that he came back.

鉴别真伪（最重要）

去掉 It is…that 后句子仍完整 → 真强调句；不完整 → 是定语从句或名词性从句。试：It was in the park that I met him. → I met him in the park. ✅ 完整，是强调句。

谓语动词强调用 do / does / did + 动词原形：He does love you. / Do come early.
句法 ⑭

省略：让句子更瘦的规则

状语从句省略（最高频）

时间/条件/让步状语从句中，主从句主语一致且从句含 be → 省略"主语 + be"：
When (he was) asked, he smiled.
While (she was) walking, she sang.
If (it is) necessary, call me.

不定式省略

前文已出现的动词，不定式只留 to：
—Would you like to go? —I'd love to.
并列不定式，第二个省 to：I want to sit down and (to) rest.

对话与惯用省略

—Are you ready? —(I am) Not yet.
so / not 替代从句：I think so. / I hope not.

定语从句省略

关系代词作宾语可省：The book (that) I bought is good.（作主语不可省）

高考考法：语法填空中 When ______ (walk) in the street, I met Tom. → 主语一致 + 主动 → 填 walking。判主动被动是关键。
句法 ⑮

独立主格：自带主语的"外挂"结构

名词 / 代词 + 分词 / 不定式 / 形容词 / 副词 / 介词短语

它不是句子（无谓语），自带逻辑主语，与主句用逗号隔开，表时间/原因/条件/伴随。

类型例句
名词 + 现在分词（主动/进行）Weather permitting, we will go hiking.
名词 + 过去分词（被动/完成）The work done, we went home.
名词 + 不定式（将发生）So many people to help him, he is sure to succeed.
名词 + 形容词/副词/介词短语He came in, face red / book in hand.
高考考法：① 与状语从句互换：Weather permitting = If weather permits；② with 复合结构是近亲：with + 名词 + 分词（With the light on, he slept.）；③ 判断关键：逗号前有自己的主语且无谓语动词 → 独立主格，选分词形式。
