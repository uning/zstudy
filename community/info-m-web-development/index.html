网页与在线应用制作

你每天刷的网页、用的在线工具——它们是怎么"长"出来的？
不是魔法，是三种技术的组合：HTML、CSS、JavaScript。
这节课，学会用代码"搭建"一个属于自己的网页。

初中信息科技 · 七年级 · 互联网应用与创新

答案藏在网页的"三层结构"里：
HTML 决定"有什么"，CSS 决定"长什么样"，JavaScript 决定"能干什么"。
三层配合，网页才能既好看又好用。

📄 网页是什么？

网页 = 用 HTML 编写的、能在浏览器中显示的文档。

网页不只"看"——现代网页还能"用"：
在线文档、在线表格、在线地图、在线游戏……
这些"能用的网页"，就叫在线应用（Web App）。
🔍 深层理解 · 比较它：传统软件要"下载安装"，在线应用"打开浏览器就能用"。微信有网页版、Office 有网页版、PS 也有网页版——"软件网页化"是互联网的大趋势。

🦴 HTML：网页的骨架

HTML（超文本标记语言）：用"标签"告诉浏览器"这里有什么"。
标签 = 用尖括号括起来的关键词，如 <h1>、<p>
<!-- 常见 HTML 标签 -->
<h1>这是一级标题</h1>
<p>这是一个段落</p>
<img src="photo.jpg"> <!-- 图片 -->
<a href="https://...">链接</a>
<button>点击我</button>

HTML 像"建筑图纸"——告诉浏览器：这里要放标题、这里要放段落、这里要放图片。

🎨 CSS：网页的皮肤

CSS（层叠样式表）：告诉浏览器"长什么样"——颜色、大小、位置、边框、阴影。
没有 CSS，网页是"毛坯房"；有了 CSS，网页是"精装修"。
/* CSS 控制样式 */
h1 {
  color: #e07b39; /* 橙色 */
  font-size: 32px; /* 字号 */
  text-align: center; /* 居中 */
}
🔍 深层理解 · 比较它：HTML 说"这里有个标题"，CSS 说"这个标题要橙色、32 像素、居中"。一个管"内容"，一个管"外观"——分工明确。

🧠 JavaScript：网页的大脑

JavaScript：让网页"动起来"——点击按钮、弹出提示、实时计算、加载数据。
没有 JS，网页是"静态海报"；有了 JS，网页是"互动应用"。
// JS 控制交互
document.getElementById("btn").onclick = function() {
  alert("你点击了按钮！");
}
🔍 深层理解 · 迁移它：HTML 是"骨架"，CSS 是"皮肤"，JS 是"大脑"。骨架支撑结构，皮肤决定颜值，大脑负责思考——三者缺一不可。

📱 在线应用：从网页到 App

简单网页 = HTML + CSS + JS，只能"看"
在线应用 = HTML + CSS + JS + 服务器数据 + 用户交互，能"用"

例：在线文档 = 网页框架（HTML）+ 界面样式（CSS）+ 编辑功能（JS）+ 云端存储（服务器）
🔍 深层理解 · 看见它：你手机里的 App，很多本质上就是"打包好的网页"——微信读书、美团、知乎，都有对应的网页版。学会网页制作，就打开了"做自己的 App"的大门。

⚠️ 三大易错点

易错点 1：以为"HTML=编程"——HTML 是"标记语言"，不是编程语言。它只描述"有什么"，不处理"逻辑"。真正的编程是 JavaScript。
易错点 2：以为"CSS 只是美化"——CSS 不只管"好看"，还管"布局"（左右排列、上下排列、响应式适配手机）。没有 CSS，网页会乱成一团。
易错点 3：以为"网页=网站"——一个网站由很多网页组成，还可能包含数据库、服务器程序。网页是"前台"，网站是"前台+后台"的完整系统。

🌟 总结与分层作业
