🔑 什么是编码？

编码 = 按约定好的规则，把信息转换成符号。
解码 = 按同样的规则，把符号翻译回信息。
🔍 深层理解 · 看见它：编码就在你身边——身份证号编码了你的出生地和生日；红绿灯用颜色编码"停和行"；条形码编码了商品的价格信息。生活中处处是编码，编码让信息传递又快又准。

💡 计算机的密码：二进制

计算机里有无数个"小开关"：开 = 1，关 = 0。
只用 0 和 1 两个数字来计数，就叫二进制。
每一个 0 或 1，叫做一个比特（bit）——它是信息的最小单位。
🔍 深层理解 · 比较它：我们日常用十进制（0~9 十个数字），因为人有十根手指；计算机用二进制（0、1 两个数字），因为开关只有开、关两种状态。用什么工具，就配什么编码。

🔤 字母和汉字也是 0 和 1

计算机给每个字符发一个"编号"：
字母 A 的编号是 65，二进制写作 01000001；
汉字 中 也有自己的编号，同样是一串 0 和 1。
这种约定叫字符编码（如 ASCII、Unicode）。
🔍 深层理解 · 迁移它：这和第四单元的"数据"连起来了！文字、声音、图片都是数据，而所有数据进计算机前，都要先"翻译"成 0 和 1 的编码。编码，是数据进计算机的"安检门"。

🖼️ 图片怎么变成 0 和 1？

把图片放大、再放大——你会看到一个个小方格，叫像素。
每个像素用一种颜色填充，每种颜色对应一串 0 和 1。
图片 = 许许多多像素的颜色编码排成的方阵。

👆 点击画布，看看笑脸是怎样由黑白像素编码出来的

⚠️ 三大易错点

易错点 1：以为二进制里"10"读作"十"——它读作"一零"，表示十进制的 2。
易错点 2：以为只有数字需要编码——文字、声音、图片、视频，全都要编码成 0 和 1。
易错点 3：编码和解码用不同规则——规则必须一致，否则翻译出来就是乱码。
